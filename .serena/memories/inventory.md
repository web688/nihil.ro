  3. Run with `--conf 0.1 --dilate 15`
  4. Check output in result folder

## CLI Tools Available

### noai-watermark (pip installed globally)
- **Version**: 0.1.29
- **Purpose**: Remove **invisible** AI watermarks (SynthID, StableSignature, TreeRing) and AI metadata
- **How it works**: Diffusion-based image regeneration — encodes image to latent space, injects noise to break watermark patterns, reconstructs via reverse diffusion
- **Install**: `pip install noai-watermark`

**Commands:**
```powershell
# Remove invisible AI watermarks (default: strength=0.04, steps=50)
noai-watermark source.png -o cleaned.png

# Check for AI metadata
noai-watermark source.png --check-ai

# Remove AI metadata only
noai-watermark source.png --remove-ai -o cleaned.png

# Higher strength for stubborn watermarks
noai-watermark source.png --strength 0.15 -o cleaned.png

# Use CtrlRegen pipeline (best quality, slower)
noai-watermark source.png --model-profile ctrlregen -o cleaned.png
```

**Options:**
| Flag | Default | Description |
|------|---------|-------------|
| `--strength` | 0.04 | Regeneration intensity (0.0-1.0) |
| `--steps` | 50 | Denoising iterations |
| `--model` | Lykon/dreamshaper-8 | SD 1.5-compatible model |
| `--model-profile` | default | `default` (img2img) or `ctrlregen` (best quality) |
| `--device` | auto | `auto`, `cpu`, `mps`, or `cuda` |

**Use cases:**
- Remove SynthID watermark from Gemini-generated images
- Strip AI metadata (prompt, seed, model info) from images
- Clean C2PA provenance from DALL-E/Adobe Firefly images

**MCP Server:** `D:\Websites\MCP\Images\noai-watermark\noai_server.py`
- Uses same venv as watermark-remover (PyTorch + CUDA)
- Tools: `remove_invisible_watermark`, `check_ai_metadata`, `remove_ai_metadata`

**Python API (direct):**
```python
from watermark_remover import WatermarkRemover
from pathlib import Path

remover = WatermarkRemover(device='cuda')
remover.remove_watermark(
    image_path=Path(r'X:\path\to\image.jpg'),
    output_path=Path(r'X:\path\to\output.jpg'),
    strength=0.04,
    num_inference_steps=50
)
```

**vs watermark-remover MCP:**
- `noai-watermark`: Invisible/embedded watermarks (SynthID, etc.) - diffusion regeneration
- `watermark-remover`: Visible watermarks (Alamy logos, text overlays) - YOLO+LaMa inpainting
